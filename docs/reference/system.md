# koopa system

(koopa-system-check)=
## `system check`

Run system checks, including dependency versions, broken app installs, bootstrap version, and disk usage.

(koopa-system-hostname)=
## `system hostname`

Print the system hostname.

(koopa-system-info)=
## `system info`

Show system information.

(koopa-system-list)=
## `system list subcommand`

List system information (subcommands: app-versions, launch-agents, path-priority).

(koopa-system-os-slug)=
## `system os-slug`

Print the operating system identifier slug.

(koopa-system-prefix)=
## `system prefix [name]`

Print the installation prefix for koopa or a named application.

(koopa-system-prune-apps)=
## `system prune-apps`

Remove stale application versions.

- `--verbose`

(koopa-system-switch-to-develop)=
## `system switch-to-develop`

Switch koopa installation to the development branch.

(koopa-system-version)=
## `system version name`

Print the installed version of an application.

(koopa-system-which)=
## `system which name...`

Print the real path of an application.
